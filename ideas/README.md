| Idea | Scene | Status |

Each idea has its own folder. After the first image is explicitly authorized, that folder will also hold the prompt, source image, 64×64 frame, enlarged review preview, and any later approved animation assets. See the [artwork workflow](../README.md#artwork-workflow).
