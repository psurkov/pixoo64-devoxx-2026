# Работа над конкурсным визуалом

- Сначала сгенерируй один статичный ключевой кадр и покажи его пользователю.
- Пока пользователь явно не одобрил этот кадр, дорабатывай только его. Не генерируй другие изображения или кадры анимации и не собирай GIF.
- После одобрения первого кадра можно готовить остальные изображения и анимацию по согласованной идее.
- Публикуй репозиторий и отправляй работу на конкурс только по явной просьбе пользователя.
